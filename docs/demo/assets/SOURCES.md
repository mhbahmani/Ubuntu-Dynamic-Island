# Presentation-only assets

- `believer-cover.jpg`: artwork for “Believer” by Imagine Dragons, downloaded from https://cdn.mos.cms.futurecdn.net/KWfYHBGd3df7k4ac8eP3uV-622-80.jpg (622×415). Displayed through the extension's existing square artwork crop.

- `telegram.svg`: Telegram's official logo, downloaded from https://telegram.org/img/t_logo.svg. Usage guidance: https://telegram.org/press.
- `whatsapp.svg`: WhatsApp's logo, sourced from https://commons.wikimedia.org/wiki/File:WhatsApp.svg (originally extracted from WhatsApp's official brand assets). Download: https://upload.wikimedia.org/wikipedia/commons/6/6b/WhatsApp.svg.

These assets are used by the recording project and are not included in the extension package.

The isolated desktop uses Ubuntu's installed `warty-final-ubuntu.png` wallpaper and Yaru icons. These remain system assets; see `/usr/share/doc/ubuntu-wallpapers/copyright` and the installed Yaru package's copyright file.
